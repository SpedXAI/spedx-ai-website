# SPEDX AI — Investor Website

A responsive single-page investor website for SPEDX AI.

## Run
Open `index.html` in a modern browser.

## Files
- `index.html` — site structure and content
- `styles.css` — responsive design and animation
- `script.js` — investor FAQ and interactions
- `intent-flow.svg`, `node-ui.svg`, `execution-ui.svg`, `trust-ui.svg` — product illustrations

The site describes SPEDX AI as idea/prototype stage and pre-revenue, without claiming unverified traction.
